# SigFleet Navigation Map

## Guest Navigation

Guests can access Home, Browse Vehicles, Vehicle Details, How It Works, Safety, Insurance, About, Contact, Login, and Register. Guests can browse listings but must log in and complete KYC before booking.

## Customer Navigation

Customers can access Dashboard, My Bookings, Browse Vehicles, KYC Verification, My Reviews, Account Settings, Wallet, Notifications, Wishlist, and Help & Support.

## Vehicle Manager Navigation

Vehicle managers can access Dashboard, Vehicles, Add Vehicle, Bookings, Availability, Statistics, Active Trips, Earnings, Profile, Payouts, and Support Tickets.

## Admin Navigation

Admins can access Dashboard, Users, Vehicle Managers, Vehicles, Manage Vehicles, Categories, KYC, Bookings, Payments, Support, Coupons, Payouts, and Settings.

## Where To Book

Customers book from Browse Vehicles, a Vehicle Detail page, city vehicle pages, or SigBot. The fastest guided option for conversational booking is SigBot. The visual browsing option is Browse Vehicles.

## Where To Add Vehicle

Vehicle managers add a vehicle from Manager Panel -> Vehicles -> Add Vehicle. Admins do not add manager vehicles for normal manager listings; admins review and approve them.

## Where To Get Help

Customers use Customer Panel -> Help & Support. Managers use Manager Panel -> Support. Admins use Admin Panel -> Support to reply and resolve tickets.
