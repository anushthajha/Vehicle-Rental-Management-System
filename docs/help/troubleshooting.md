# Troubleshooting FAQ

## Booking Button Disabled

The booking button can be disabled if the vehicle is unavailable, dates are invalid, the user is not logged in, the customer KYC is not approved, or the logged-in role is manager/admin instead of customer.

## Vehicle Not Showing In Search

A vehicle may not show in search if it is not admin approved, unavailable, blocked for the selected date, outside the city filter, outside the price filter, or assigned to a different type/category than selected.

## Payment Amount Looks Different

Payment amount should match the backend booking total. It may include base fare, insurance, platform fee, chauffeur fee, and coupon discount. If it looks wrong, refresh the booking and contact support.

## KYC Pending

If KYC is pending, wait for admin review. If rejected, check the rejection reason, correct the details, and submit again.

## Manager Vehicle Pending

If a vehicle is pending, wait for admin approval. Review all details and photos to avoid rejection.

## Cannot Cancel Booking

Some bookings may not be cancellable depending on status or timing. Open the booking details page or ask SigBot to show eligible active bookings and cancellation preview.

## No Notifications

If there are no notifications, the bell dropdown and notifications page may show an empty state. New events such as payments, support replies, approvals, or booking updates create notifications.

## Help Assistant Cannot Answer

The Help Assistant answers application usage questions from the knowledge base. For live inventory, exact payment disputes, account-specific issues, or private booking problems, use Browse Vehicles, SigBot, or Support.
