# Common SigFleet Help

## SigBot vs Help Assistant

SigBot is the customer booking assistant. It helps customers search vehicles, calculate price, create bookings, cancel bookings, and move to payment. The Help Assistant answers application usage questions for guests, customers, vehicle managers, and admins.

Use SigBot for booking actions. Use the Help Assistant for questions like where to find a feature, how to complete a workflow, or what steps to follow.

## Daily Brief Agent

The Daily Brief is a read-only AI summary shown on dashboards. It gives a short personalised greeting and summary based on the user role. Customers may see booking or wallet reminders. Managers may see fleet or earnings updates. Admins may see pending approvals or platform metrics.

## Notifications

Notifications appear from the bell icon. Users can mark notifications as read, view all notifications, and delete notifications. Admins receive notifications for important platform events like new manager registrations.

## Support

Support is used when a user has a problem that cannot be solved through normal app actions. Customers can create tickets. Staff can reply and update ticket status.

## Roles

SigFleet has three main roles. Customers book vehicles and manage trips. Vehicle managers list vehicles and handle trips. Admins review users, KYC, vehicles, support, payments, and platform operations.
