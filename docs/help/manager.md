# Vehicle Manager Help

## Add a Vehicle

Vehicle managers can add a car, bike, or traveller from Manager Panel -> Vehicles -> Add Vehicle. Fill vehicle type, category, registration number, model details, pricing, trip limits, features, location, and photos. New vehicles require admin approval before customers can book them.

Steps:
1. Open Manager Panel.
2. Go to Vehicles.
3. Click Add Vehicle.
4. Select vehicle type and category.
5. Enter registration and vehicle details.
6. Set price per hour, price per day, minimum trip duration, and maximum trip duration.
7. Add location, features, and photos.
8. Submit for admin approval.

## Manage Vehicles

Managers can view their listed vehicles from Manager Panel -> Vehicles. They can edit details, update pricing, manage photos, and change availability. Vehicles pending approval are not bookable until an admin approves them.

## Manage Bookings

Managers can review bookings from Manager Panel -> Bookings. Depending on booking status, managers can inspect vehicles, track active trips, end trips, and view booking details. Auto-accepted vehicles may directly create confirmed bookings.

Steps:
1. Open Manager Panel -> Bookings.
2. Review pending, confirmed, or active bookings.
3. Use inspection before pickup and after return.
4. Track active rentals from Active Trips.
5. End the trip after return details are submitted.

## Availability

Managers can manage vehicle availability from the Availability section. Block dates when a vehicle is unavailable due to maintenance, personal use, or operational reasons.

## Earnings and Payouts

Managers can view earnings from Manager Panel -> Earnings. Completed and paid trips contribute to manager earnings. Payout requests can be managed from Payouts after bank and account details are ready.

Steps:
1. Open Manager Panel -> Earnings.
2. Review monthly revenue and transaction history.
3. Open Payouts.
4. Request withdrawal when eligible.

## Support Tickets

Managers can access support tickets from the manager support section. They can respond to booking or vehicle-related issues assigned to them.
