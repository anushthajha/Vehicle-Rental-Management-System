# SigFleet Glossary

## SigBot

SigBot is the customer booking chatbot. It helps search vehicles, calculate price, create bookings, cancel bookings, and guide customers to payment.

## Help Assistant

Help Assistant is the FAQ/RAG assistant. It answers how-to questions about using SigFleet across guest, customer, manager, and admin roles.

## Daily Brief

Daily Brief is a personalised AI dashboard banner. It appears on dashboards and summarises role-specific updates.

## KYC

KYC means Know Your Customer. Customers submit identity and driving licence details for admin approval before booking.

## Vehicle Manager

Vehicle Manager is the role that lists vehicles, manages bookings, handles active trips, and receives earnings.

## Admin

Admin is the platform operations role that reviews users, managers, vehicles, KYC, payments, support, coupons, and platform data.

## Booking

Booking is a customer reservation for a vehicle for a selected pickup and return time.

## Active Trip

Active Trip is a booking currently in progress after pickup and before return completion.

## Availability

Availability means whether a vehicle can be booked for selected dates. It depends on vehicle status, approval, blocks, and existing bookings.

## Wallet

Wallet stores customer balance, refunds, added money, and related transactions.
