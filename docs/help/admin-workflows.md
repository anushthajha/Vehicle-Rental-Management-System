# Admin Workflow FAQ

## Admin Dashboard Metrics

Admin Dashboard shows platform health such as active trips, pending vehicles, pending KYC, pending managers, support tickets, payments, revenue, and user counts.

## User Management

Admins manage customers, managers, and account statuses from Admin Panel -> Users. Use user management to review accounts, activity, verification, and access status.

## Manager Registration Notifications

When a vehicle manager registers, admins receive an in-app notification and email alert when configured. Admins review the manager from Users -> Vehicle Managers.

## KYC Approval

Admins approve customer KYC from Admin Panel -> KYC. Check submitted identity and licence information before approving. Reject invalid submissions with a clear reason.

## Vehicle Moderation

Admins moderate vehicle listings from Admin Panel -> Vehicles. Review title, type, category, pricing, location, images, and manager before approval.

## Category Management

Admins manage vehicle categories and vehicle types from Admin Panel -> Categories. Categories affect filters, manager vehicle forms, and customer search results.

## Coupon Management

Admins create and manage coupon codes from Admin Panel -> Coupons. Coupons can define discount type, discount value, maximum discount, minimum booking amount, validity dates, and usage rules.

## Payment Review

Admins can review payment records from Admin Panel -> Payments. Payment data helps investigate successful, pending, failed, or refunded transactions.

## Payout Review

Admins can monitor manager payouts from Admin Panel -> Payouts. Payouts are connected to completed bookings and manager earnings.

## Support Operations

Admins handle support from Admin Panel -> Support. Use status and priority to manage the queue. Reply to customers and resolve tickets after the issue is handled.

## Platform Settings

Admin settings are used for operational controls and future platform configuration. Only admins should access platform-wide settings.
