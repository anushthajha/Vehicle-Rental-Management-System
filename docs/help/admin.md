# Admin Help

## Dashboard Overview

Admins use the Admin Dashboard to monitor active trips, pending KYC, pending vehicle approvals, pending manager approvals, payments, support tickets, and platform revenue.

## Approve Vehicle Managers

Admins approve or reject vehicle manager registrations from Admin Panel -> Users -> Vehicle Managers. New managers must be reviewed before they can fully operate on the platform.

Steps:
1. Open Admin Panel.
2. Go to Users.
3. Open Vehicle Managers.
4. Review pending manager registrations.
5. Approve eligible managers or reject with a reason.

## Approve Vehicles

Admins approve vehicles from Admin Panel -> Vehicles. Review vehicle details, manager, category, type, location, pricing, and photos before approval. Approved and available vehicles become visible for customer booking.

Steps:
1. Open Admin Panel -> Vehicles.
2. Filter or identify pending vehicles.
3. Review vehicle information and photos.
4. Approve valid listings or reject incomplete ones.

## Manage Users

Admins can view users from Admin Panel -> Users. They can inspect customers, managers, account status, and activity. Suspicious or inactive accounts can be managed from the admin controls.

## KYC Review

Admins review customer KYC submissions from Admin Panel -> KYC. They approve valid identity and licence details or reject invalid submissions with a reason.

## Support Tickets

Admins manage support tickets from Admin Panel -> Support. They can read customer messages, reply as staff, change ticket status, set priority, and mark issues resolved.

Steps:
1. Open Admin Panel -> Support.
2. Select a ticket.
3. Read the original issue and message thread.
4. Reply to the customer.
5. Update status and priority.

## Categories and Coupons

Admins manage vehicle categories, vehicle types, and coupons from the admin panel. Categories and types control how vehicles are listed and filtered. Coupons control discounts and eligibility.
