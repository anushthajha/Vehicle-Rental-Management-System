# Manager Workflow FAQ

## Manager Dashboard

The manager dashboard summarises fleet size, active trips, bookings, earnings, pending approvals, and important reminders. The Daily Brief may also highlight manager-specific fleet updates.

## Vehicle Approval Status

New vehicles are usually pending until admin approval. Pending vehicles are not visible for customer booking. If a vehicle is rejected, review the reason, edit details, and submit again.

## Add Bike Listing

To add a bike, open Manager Panel -> Vehicles -> Add Vehicle, choose vehicle type Bike, select a bike category such as scooter, cruiser, sport bike, or adventure, enter registration and pricing, then upload photos and submit.

## Add Traveller Listing

To add a traveller, open Add Vehicle, choose vehicle type Traveller, select traveller category, set seat capacity, pricing, photos, location, and submit for admin approval.

## Pricing Setup

Managers set price per hour, price per day, minimum trip hours, maximum trip days, security deposit, included kilometres, and extra kilometre charges. These values affect booking price calculation.

## Availability Blocks

Use Availability to block dates when a vehicle should not be booked. Maintenance, personal use, or operational issues should be blocked in advance.

## Booking Request Flow

Bookings appear in Manager Panel -> Bookings. Auto-accepted vehicles may directly create confirmed bookings. Other bookings may need manager review depending on settings.

## Vehicle Inspection

Inspection records pickup and return condition. Managers should record odometer, condition notes, and damages where relevant before completing a trip.

## Active Trips

Active Trips shows vehicles currently rented by customers. Managers can track trip status and prepare for return inspection.

## Manager Profile

Managers can update profile details and operational information from Manager Profile. Good profile details improve trust with customers.

## Super Manager

Strong completion record, good reviews, and reliable service can contribute to manager reputation and super manager status when enabled by platform rules.

## Manager Support

Managers can use Support Tickets for issues involving customers, bookings, vehicle damage, payments, payouts, or listing problems.
